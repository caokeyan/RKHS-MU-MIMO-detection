\section{评价指标与相对增益定义}
\label{sec:metric}

对期望用户符号索引 $\hat X_1,\ X_1\in\{0,\ldots,|\mathcal{A}|-1\}$，采用 Gray 标注的 I/Q 比特映射，定义 bit 误码率
\begin{equation}
\mathrm{BER}
=\frac{1}{N_{\mathrm{bit}}}
\sum_{i=1}^{N_{\mathrm{te}}}
\sum_{b=1}^{\log_2|\mathcal{A}|}
\mathbf{1}\!\left\{
\mathrm{bit}_b(X_1^{(i)})\neq\mathrm{bit}_b(\hat X_1^{(i)})
\right\},
\label{eq:ber}
\end{equation}
其中 $N_{\mathrm{bit}}=N_{\mathrm{te}}\log_2|\mathcal{A}|$。除特别声明外，下文“BER”均指式\eqref{eq:ber}。

为量化可部署 RKHS 相对线性基线的边际收益，定义相对 MMSE+LS 的 BER 降幅
\begin{equation}
G
=\frac{\mathrm{BER}_{\mathrm{MMSE}}-\mathrm{BER}_{\mathrm{RKHS}}}{\mathrm{BER}_{\mathrm{MMSE}}}
\times 100\%.
\label{eq:gain}
\end{equation}
$G>0$ 表示 RKHS 优于 MMSE；$G<0$ 表示劣于 MMSE。多信道实验时，先对每条信道独立估计 BER，再对信道取算术平均得到 $\overline{\mathrm{BER}}$，最后用 $\overline{\mathrm{BER}}$ 代入式\eqref{eq:gain}。该定义与实现中 \texttt{gain\_pct} 字段一致。

对照方法含义如下：
\begin{itemize}[leftmargin=2em]
  \item \textbf{MLD}：真 $H$ 下对 $X_1$ 的边际近似（高斯干扰近似 / Monte Carlo），贝叶斯最优参照；
  \item \textbf{Oracle}：真 $H$ 的 struct 特征 + 真后验 $f^*$ 的 RKHS 闭式拟合（可逼近性上界）；
  \item \textbf{RKHS $z_{\mathrm{rob}}$}：可部署主线（$\hat H$ + hard + Adaptive-MKL，见第\ref{ch:method}章）；
  \item \textbf{MMSE+LS}：同一导频 LS 信道上的线性 MMSE 估计再硬切片。
\end{itemize}

\section{扩展实验 A：线性场景至高 SNR}

\section{扩展实验 B：多前端失真（16-QAM）}
\label{sec:exp-nonlin16}

\subsection{实验动机与设定}

实际接收链路在 $Y=HX+N$ 之后，往往还存在\textbf{无记忆前端失真}：射频限幅、功放/光纤类非线性、本振相位噪声、I/Q 失衡等。这些效应使真实观测偏离线性高斯模型，而基站侧检测器若仍按线性模型工作，即构成\textbf{模型失配}。

本实验的目的\textbf{不是}为每一种前端单独重训一套检测器，而是回答：
\begin{quote}
在检测器内部仍使用线性模型假设 + $z_{\mathrm{rob}}$+RKHS 的前提下，同一套可部署流水线能否在多种失真下相对 MMSE+LS 保持增益？
\end{quote}
因此：
\begin{itemize}[leftmargin=2em]
  \item 数据生成：先按式\eqref{eq:sys} 得到 $Y$，再施加表\ref{tab:nonlin-cfg} 的失真得到 $\tilde Y$；
  \item 检测器：对 $\tilde Y$ 运行与线性场景相同的可部署 RKHS / MMSE+LS（均不知失真的解析形式）；
  \item 指标：仍用式\eqref{eq:ber}--\eqref{eq:gain}；SNR 网格 $\{0,4,8,12,16\}$\,dB，$n_{\mathrm{chan}}=2$。
\end{itemize}
失真参数取表\ref{tab:nonlin-cfg} 的固定标称值，用于兼容性扫查而非精细标定。

\section{扩展实验 D：更真实信道（Sionna CDL / Kronecker）}
\label{sec:exp-realistic}

为降低“仅 i.i.d.\ Rayleigh”的质疑，补充两类信道（\textbf{检测流水线不变}，仍为 $\hat H$+$z_{\mathrm{rob}}$+Adaptive-MKL）：
\begin{itemize}[leftmargin=2em]
  \item \textbf{Kronecker 空间相关}：$H=R_{\mathrm{rx}}^{1/2}GR_{\mathrm{tx}}^{1/2}$，指数相关 $\rho_{\mathrm{rx}}=0.5$，$\rho_{\mathrm{tx}}=0.3$，列功率归一；
  \item \textbf{3GPP CDL}（NVIDIA Sionna TR\,38.901）：上行 CDL-A / CDL-C，基站 $8\times16$ 面板（$M=128$），$K=40$。
\end{itemize}

\paragraph{CDL 多用户构造说明.}
标准 CDL 是单链路簇延迟线模型，簇到达角相对阵列几何\textbf{固定}。若对 $K$ 个用户共用同一基站朝向，则各用户信道落入近乎相同的角度子空间，条件数可达 $10^2$--$10^3$，此时即便线性 MLD/MMSE 也会出现不可接受的误码地板。本报告的多用户设定为：对每个用户独立采样基站方位角（\texttt{bs\_orientation} 的 batch 维），等效于用户分布在不同到达角；生成后仍做列功率归一。该设定下条件数与 Kronecker 同量级（约 $10^0$--$10^1$），线性场景下 MLD 可回到近零误码，与物理可分的上行 MU-MIMO 一致。

\paragraph{配置.}
16-QAM，$N_{\mathrm{tr}}=2200$，$N_{\mathrm{te}}=3000$，2 条信道实现，SNR $\{0,4,8,12\}$\,dB；场景优先 soft\_clip / hard\_clip / linear。相对增益仍按式\eqref{eq:gain}、先信道平均再算 $G$。

\section{结果综合与局限}

\begin{enumerate}[leftmargin=2em]
  \item \textbf{中期（0--10\,dB，16-QAM）}：可部署 RKHS 相对 MMSE 约 $19\%$--$35\%$ BER 降低；Oracle$\approx$MLD。
  \item \textbf{多前端失真}：同一 $z_{\mathrm{rob}}$+RKHS 流水线在幅度型失配下可取得约 $23\%$--$52\%$ 的平均 $G$（表\ref{tab:gain16}--\ref{tab:qam64-gain}）。
  \item \textbf{更真实信道}：Kronecker 上 soft-clip 平均 $G\approx 39\%$（表\ref{tab:kron-gain}）；修复多用户角度后的 CDL-A soft-clip 平均约 $19\%$（表\ref{tab:cdl-gain}），说明增益不只依赖 i.i.d.\ Rayleigh。
  \item \textbf{高 SNR 线性}：通过将正则 $\lambda$ 降至 $0.01$--$0.03$ 并将测试样本扩至 $2\times10^{4}$，16-QAM 线性 0--14\,dB 全程 $G>0$（$+20\%$--$+52\%$，峰值在 12\,dB），消除了此前因测试样本不足（稀有错误）导致的负增益。64-QAM 线性在 16--20\,dB 仍可能翻负，属同一稀有错误瓶颈。
  \item \textbf{64-QAM}：流水线可迁移；应关注相对增益而非绝对 BER 的跨调制直接比较。
\end{enumerate}

局限：无记忆失真为简化前端；真实信道实验按算力裁剪（2 信道、4 点 SNR）；CDL 采用每用户随机方位以构造可分 MU，与“单几何重复 $K$ 次”的错误用法不同；64-QAM 每类样本更少；实时复杂度未系统评估。

扩展实验入口：\texttt{python run\_extended\_exp.py --only realistic --channel \{kronecker|cdl\_a|cdl\_c\}}；数值见 \texttt{extended\_results/qam16/ch\_*/}。

\chapter{讨论、展望与结论}
\label{ch:discuss}

\section{理论图景的再表述}

把本工作的理论图景压缩为三句话：
\begin{enumerate}[leftmargin=2em]
  \item 贝叶斯最优检测等价于掌握后验 $f^*$；学习检测器应直接以 $J(f)$ 逼近该目标。
  \item RKHS 提供可分析的假设类；在与 GA-MLD 对齐的 $|\mathcal{A}|$ 维坐标上，核方法具有现实可逼近性。
  \item 可部署性迫使坐标改为 $z_{\mathrm{rob}}(\hat H)$、监督改为 hard；性能损失主要来自信息减损，应用稳健加载与 MKL 表达去弥补。
\end{enumerate}

\section{与深度学习路线的关系}

本方法不排斥神经网络，而是把 NN 限制在\textbf{核系数生成器}位置，从而保留 $K_\eta\alpha^\top$ 的可解释决策形式。若未来引入更深的端到端网络，建议仍以 $J$ 为主要目标，并显式建模 CSI 不确定度，以免重复“把 $\hat H$ 当真 $H$”的错误。

\section{后续工作}

\begin{enumerate}[leftmargin=2em]
  \item \textbf{验证选择稳定化}：联合 BER+$J$ 选模，减少单次验证噪声导致的回退；
  \item \textbf{中心选择}：按 margin / 类平衡构造字典，替代纯随机子集；
  \item \textbf{SNR 自适应}：加载强度、$\lambda$、基核组随 SNR 平滑调度；
  \item \textbf{更真实信道}：空间相关、上行导频污染、量化接收；
  \item \textbf{复杂度}：Nyström、随机特征、滑动字典，面向实时；
  \item \textbf{多用户扩展}：由只检 $X_1$ 扩展到分组检测或软干扰消除外环。
\end{enumerate}

\section{结论}

本报告围绕大规模 MU-MIMO 单用户边际检测，建立了以 RKHS 为假设类、以贝叶斯后验损失为主目标的方法体系。通过稳健特征 $z_{\mathrm{rob}}$、Adaptive-MKL 与核内学习增强，在 $128\times40$、16-QAM、0--10\,dB 设定下取得相对 MMSE+LS 约 19\%--35\% 的 BER 降低；在多种无记忆前端失真及 64-QAM 迁移实验中，相对增益 $G$ 在幅度型失配场景可进一步扩大（详见第\ref{ch:exp}章）。通过 struct+$f^*$ Oracle 实证了核空间对后验的可逼近性。工作表明：\textbf{通信结构（充分统计与 CSI 稳健化）与核学习（表示定理与 MKL）的结合}，是一条介于经典线性接收与黑盒深度检测之间、值得继续深化的技术路线。
